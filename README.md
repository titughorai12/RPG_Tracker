\# RPG Tracker



RPG Tracker is a gamified life-management web application.



\## Features



\- User Registration and Login

\- Create Tasks / Quests

\- Complete Quests

\- Earn XP

\- Level Up

\- Earn Coins

\- Shop

\- Inventory

\- Streak System

\- Character Attributes

\- PostgreSQL Database



\## Technology



Frontend:

HTML, CSS, JavaScript



Backend:

Python, Flask



Database:

PostgreSQL

\## Project Purpose



RPG Tracker converts everyday tasks into RPG-style quests.



Users complete tasks, earn XP and coins, level up their character, maintain streaks, buy rewards, and manage their inventory.



\## Security



Passwords are securely hashed.



Environment variables are kept private and are not uploaded to GitHub.
